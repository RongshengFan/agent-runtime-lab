# Concepts

只记录已经能够用自己的语言解释清楚的 Agent Runtime 概念。

建议优先补齐：

- Agent vs Chat vs Workflow
- Agent Loop
- Turn / Step / Run / Session
- Context vs Memory vs Persistence
- Tool schema / registry / execution
- Streaming / cancellation / retry
- Permission / approval / sandbox
- Compaction
- Subagent / agent-as-tool / handoff

每篇概念笔记尽量回答四个问题：

1. 它是什么？
2. 为什么需要它？
3. 最小实现是什么？
4. 生产级系统还要解决什么？
